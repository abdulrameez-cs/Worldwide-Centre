# WWC Attendance App

Files: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png

## Put it on GitHub Pages
1. github.com -> New repository (name e.g. `wwc-attendance`, Public) -> Create.
2. Add file -> Upload files -> upload ALL 5 files above -> Commit.
3. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
4. After 1-2 minutes your app is at https://YOUR-USERNAME.github.io/wwc-attendance/

## Install on phone
- Android (Chrome): open the link, menu (3 dots) -> Install app / Add to Home screen.
- iPhone (Safari): open the link, Share -> Add to Home Screen.
Open it once with internet; after that it also works offline.

## Move old data
In the old app: Setup -> Download backup. In the new app: Setup -> Restore.
